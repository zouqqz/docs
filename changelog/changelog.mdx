<Update label="2026年9月" description="v1.17.6">
  **一、功能优化**

  - Overlay 节点现支持手动配置放行网段及节点级 IP 独立设置。
  - 扩展 Z 零配置关联方式：支持按分组（Group）和标签（Tag）批量导入设备。
  - 产品模型新增隐藏规则与初始化规则，支持按设备类型、固件版本动态控制 UI 显隐。
  - 流量提醒阈值由百分比调整为固定大小，默认 5GB。
  - 修复部分 BUG。

  **二、影响范围**

  - 产品管理模块：规则引擎需支持解析新增的隐藏/初始化字段。
  - 设备兼容性：需部署支持新 Yang 模型的固件版本（v1.17.6+）。
  - 配置与 UI：流量提醒默认阈值需同步更新数据库配置。
  - 兼容性：无系统架构及核心流程变更，存量数据无缝兼容，升级风险可控。
</Update>

<Update label="2026年8月" description="v1.17.5">
  **一、功能优化**

  - 固件推送逻辑优化：推送后，租户需手动选择设备进行升级；设备不再自动关联所有固件推送。
  - 租户设备升级的固件下拉菜单现在仅展示与设备产品对应的固件以及租户自行上传的固件。
  - 新增系统通知管理：系统管理员现可发布通知，租户侧将展示未读数量及通知列表。
  - 新增套餐/配额不足自动通知：管理员可配置阈值，后台将定期检查并据此发送通知。
  - 新增套餐订阅提醒：租户订阅套餐后，管理员将收到确认计费/付款的提醒。
  - 优化短信/邮件通知方式，支持可选配置。

  **二、影响范围**

  - 固件管理模块：推送、删除及产品关联的逻辑调整将影响租户的操作流程。
  - 系统通知模块：新增通知管理能力、租户侧展示及套餐自动通知功能。
  - 权限与展示：海外版的通知方式现已可配置，影响开发者与租户的可见性。
  - 兼容性：无 API 变更，无数据结构变更，升级风险可控。
</Update>

<Update label="2026年8月" description="v1.17.4">
  **一、功能优化**

  - 在 HMP 设备表单模式下，ip address 和 no ip address 参数现已支持自动同步与赋值。
  - 在 HMP 设备高级模式下，CLI 参数现以原始 CLI 格式展示。
  - 修复了 HMP 设备在一行中存在多个参数时仅推送单个参数的问题。
  - 在产品模型参数规则中新增 "Initialize" 字段。未勾选的参数在设备初始开通时不会被推送。
  - 对于 ATU 设备，表单模式现仅展示产品模型中配置的参数，高级模式则允许查看设备全部参数。
  - 优化了文件清理功能；用户上传的文件不再被删除。

  **二、影响范围**

  - 参数配置模块（CLI / ALink 协议）：对参数展示、推送逻辑及初始化策略进行了调整。
  - 产品模型管理：在参数规则中新增了 "Initialize" 配置项。存量数据默认为"已初始化"，无需迁移。
  - 文件管理：上传文件的保留策略已变更；文件不再被自动清理。
  - 兼容性：无 API 变更或数据结构修改。
</Update>
